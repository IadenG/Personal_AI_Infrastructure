# HOK — Listing Templates
**Purpose:** Give Kairos watch details → get a platform-ready listing back.
**How to use:** Copy the brief prompt below, fill in the watch info, paste into Kairos.

---

## How to Brief Kairos for a Listing

```
Kairos — I need a listing for [PLATFORM]. Here's the watch:

Brand/Model:
Reference number:
Year (approximate if unknown):
Case size:
Movement:
Condition (case / dial / bracelet):
Service history (if known):
Included (box, papers, extra links, etc.):
Asking price:
Any story or notable detail:

Generate the full listing.
```

## Condition Grading Reference

Use these terms consistently across all platforms:

| Grade | Meaning |
|---|---|
| **Unworn / NOS** | Never worn, full stickers if applicable |
| **Mint** | Worn rarely, no marks visible under normal light |
| **Excellent** | Light wear, no deep scratches, original surfaces intact |
| **Very Good** | Normal wear, minor scratches consistent with age and use |
| **Good** | Visible wear, scratches present, may show polishing |
| **Fair** | Heavy wear, significant scratches or damage, priced accordingly |

Always grade separately: case · dial · bracelet/strap · crystal.

## Notes for Kairos

- Never overstate condition. Accurate descriptions protect HOK's long-term reputation.
- Dial condition is paramount — lead with it if exceptional, disclose honestly if not.
- Papers and box add significant value — itemize exactly what is present.
- Platform pricing calibration: eBay buyers expect more negotiation room than Chrono24 collectors.
- For Instagram, story matters more than spec sheet. For Reddit and eBay, honesty and specs matter most.
- When in doubt, describe conservatively and price accordingly. One clean transaction builds more than one oversold one damages.
